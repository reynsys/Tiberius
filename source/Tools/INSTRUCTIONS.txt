TIBERIUS - a sci-fi HUD theme for KDE Plasma 6
==============================================

INSTALL
 1. Install the helper programs (they draw the windows and buttons, and play the
    moving wallpaper). In a terminal:
      Fedora:           sudo dnf install kvantum aurorae qt6-qtmultimedia
      Arch / CachyOS:   sudo pacman -S kvantum aurorae qt6-multimedia qt6-multimedia-ffmpeg
      Debian / Ubuntu:  sudo apt install qt-style-kvantum qml6-module-qtmultimedia
 2. Unpack Tiberius-theme.zip, open the Tiberius-theme folder, right-click an empty
    spot and choose "Open Terminal Here". Type:
      bash install.sh
 3. Log out and back in. The look is now on, with the moving wallpaper.
    (Plasma can't play video wallpapers by itself. The installer adds the free
    "Smart Video Wallpaper Reborn" add-on and sets the Tiberius video for you.)

 4. Finishing touches (optional):
    - Clock:    right-click the panel > Add or Manage Widgets, search "Tiberius",
                drag "Tiberius Clock" (and "Tiberius Keyboard Layout" if you use two
                languages) onto the panel. Right-click the old clock > Remove.
    - Menu:     right-click the Start button > Configure > click the icon > Choose,
                search "tiberius-logo".
    - Panel:    46 pixels high and floating looks best (right-click > Show Panel Configuration).

GO BACK
    In the same folder:   bash install.sh --uninstall
    Your settings from before are restored. Log out and back in.

GOOD TO KNOW
    - Nothing is installed system-wide; no password is needed for the theme itself.
    - Firefox, VSCode and some other apps draw their own windows and keep their look.
    - Still picture instead of the moving one? The installer tells you at the end.
      Install the multimedia package from step 1 and run  bash install.sh  again.
    - The video pauses while a window is maximised or full screen, to save power.
    - If windows look cut off at the bottom-right: System Settings > Window Decorations >
      Tiberius > set the border size to "Very Large".
